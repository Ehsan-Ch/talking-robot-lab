03 / HOW IT WORKS

Small vocabulary. Visible decisions.

Milo turns a single command into an intent, checks the room, then moves one cell at a time. Destination commands use a shortest-path search around obstacles.

Hear / type→Understand→Plan→Act + reply

This is a rule-based simulation, not an LLM or a hardware controller. “Forward” follows the arrow on Milo; rows count from the top. Movement commands are rejected while a route is active. Stop works at any time.
